# Assets 资源文件说明

本目录存放插件的图标和视觉资源。当前为占位文件，请替换为你自己的设计。

## 需要准备的文件

### 1. 扩展图标 (必需)

浏览器扩展需要以下尺寸的 PNG 图标：

| 文件名 | 尺寸 | 用途 |
|--------|------|------|
| `icon16.png` | 16×16 | 浏览器工具栏、扩展管理页面小图标 |
| `icon48.png` | 48×48 | 扩展管理页面、Windows 任务栏 |
| `icon128.png` | 128×128 | Chrome Web Store 商店展示 |

**设计建议：**
- 使用简洁的设计，小尺寸时仍能识别
- 推荐圆角正方形背景 + 简单图形/文字
- 避免过多细节，16px 时很难看清

### 2. 悬浮球图标 (可选)

| 文件名 | 建议尺寸 | 说明 |
|--------|----------|------|
| `float-icon.png` | 48×48 | 悬浮球默认图标，显示时缩放为 28×28 |

如果不提供，代码会使用内置 SVG 图标。

### 3. 自定义图标 (用户上传)

用户可以在设置页面上传自定义悬浮球图标，存储在浏览器本地存储中，无需在此准备。

## 文件格式要求

- **格式**: PNG (推荐) 或 SVG
- **背景**: 建议 transparent 透明背景
- **颜色**: 与主题配色协调（默认蓝 `#2196F3`）

## 如何替换

1. 设计好你的图标（可使用 Figma、Canva、IconFont 等工具）
2. 导出为 PNG 格式，生成 16/48/128 三种尺寸
3. 将文件放入本目录：
   ```
   src/assets/
   ├── icon16.png
   ├── icon48.png
   ├── icon128.png
   └── float-icon.png (可选)
   ```
4. 如使用 PNG，删除对应的 `.svg` 占位文件
